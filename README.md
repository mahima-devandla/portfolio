# 🌐 Mahima Devandla — Portfolio

🚀 Live Site: [mahimadevandla.io](https://mahimadevandla.io/)  

A modern, responsive personal portfolio built to showcase my projects, skills, and experience.  
This website is designed to represent my personal brand and provide a central place for recruiters, collaborators, and peers to explore my work.

---

## ✨ Features
- 📱 **Responsive Design** – Works seamlessly on desktop, tablet, and mobile  
- 🎨 **Dark / Light Mode Toggle** – User-friendly theme switch  
- 🚀 **Blazing Fast Performance** – Powered by [Vite](https://vitejs.dev/)  
- 📂 **Project Showcase** – Highlights key projects with live demos and code links  
- 🛠 **Easy to Customize** – Modular, clean, and maintainable code structure  
- ⚡ **Modern Tech Stack** – Built with TypeScript + Tailwind CSS  

---

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, TypeScript  
- **Styling:** Tailwind CSS  
- **Build Tool:** Vite  
- **Version Control:** Git & GitHub  
- **Deployment:** Netlify / Vercel / GitHub Pages  

---

## 📦 Installation & Setup

Clone the repository and run it locally:

```bash
# Clone the repo
git clone https://github.com/mahima-devandla/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
